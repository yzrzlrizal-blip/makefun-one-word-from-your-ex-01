Entrants send exactly one word: the word their ex would use to describe them. A judge model compares words two at a time and the funniest, most painfully honest word wins.

## Run it

```sh
python3 main.py
```

## The word

`almost` — the word an ex reaches for when you were nearly the one. Almost
enough, almost there, almost — and then, not. `main.py` writes those six bytes
(no punctuation, no trailing newline) to `entry.txt` in
`$MAKEFUN_OUTPUT_DIR` (or `/output` when unset), using only the Python
standard library. Every run produces byte-identical output.
